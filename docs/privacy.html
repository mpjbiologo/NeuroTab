Português

Resumo: a NeuroTab não tem servidor nem conta própria, não usa análise de uso (analytics) e não vende nem compartilha dados. Tudo o que você cria (atalhos, notas, tarefas, fotos, configurações) fica guardado no seu navegador, no armazenamento local da extensão.

Esses serviços têm políticas de privacidade próprias. A NeuroTab não envia identificadores, e-mail nem histórico de navegação a nenhum deles.

Permissões

Cotações, endereços do Trânsito, fotos do Bing/NASA, histórico de mais visitados, abas fechadas e acesso a outros sites são opcionais: o navegador pede sua autorização na primeira vez que você usa o recurso. As chaves de API ficam só no seu navegador e só entram no backup exportado se você marcar essa opção (com senha opcional para criptografá-las).

Contas Google e dados das APIs do Google

O uso e a transferência, pela NeuroTab, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados da sua conta são usados só para os recursos que você ligou (por exemplo, sincronizar suas notas), não são enviados a nenhum outro lugar, não são usados para publicidade nem para treinar modelos de IA, e nenhuma pessoa os lê. Você pode desconectar a conta a qualquer momento em Configurações → Contas e sincronização (isso revoga o acesso) e apagar os dados da nuvem pelo botão "Apagar dados da nuvem".

Seus dados, seu controle

Você pode exportar tudo (Configurações → Backup), apagar notas e tarefas, esvaziar a lixeira ou remover a extensão, o que apaga os dados locais. O código é aberto: github.com/mpjbiologo/NeuroTab.

English

Summary: NeuroTab has no server, no account of its own and no analytics, and it does not sell or share data. Everything you create (shortcuts, notes, tasks, photos, settings) is stored in your browser, in the extension's local storage.

These services have their own privacy policies. NeuroTab sends no identifiers, e-mail or browsing history to any of them.

Permissions

Quotes, Traffic addresses, Bing/NASA photos, top sites, recently closed tabs and access to other sites are optional: the browser asks you the first time you use the feature. API keys stay in your browser and only go into an exported backup if you tick that option (with an optional password to encrypt them).

Google accounts and Google API data

NeuroTab's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Your account data is used only for the features you turned on (for example, syncing your notes), is not sent anywhere else, is not used for advertising or to train AI models, and no human reads it. You can disconnect the account at any time in Settings → Accounts & sync (this revokes access) and delete the cloud data with "Delete cloud data".

Your data, your control

You can export everything (Settings → Backup), delete notes and tasks, empty the trash or remove the extension, which deletes the local data. The code is open source: github.com/mpjbiologo/NeuroTab.

Contact

Questions: open an issue at github.com/mpjbiologo/NeuroTab/issues.

Permisos

Las cotizaciones, las direcciones de Tráfico, las fotos de Bing/NASA, los sitios más visitados, las pestañas cerradas y el acceso a otros sitios son opcionales: el navegador te pide permiso la primera vez que usas la función. Cuentas de Google y datos de las API de Google

El uso y la transferencia, por parte de NeuroTab, de información recibida de las API de Google cumplen la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado. Los datos de tu cuenta se usan solo para las funciones que activaste (por ejemplo, sincronizar tus notas), no se envían a ningún otro lugar, no se usan para publicidad ni para entrenar modelos de IA, y ninguna persona los lee. Puedes desconectar la cuenta en cualquier momento en Configuración → Cuentas y sincronización (esto revoca el acceso) y borrar los datos de la nube con "Borrar datos de la nube".
